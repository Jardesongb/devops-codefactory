# Projeto Transformação DevOps - CodeFactory Solutions

## 1. Descrição do Projeto
Este repositório contém a proposta de modernização e estruturação dos processos de desenvolvimento da empresa CodeFactory Solutions, aplicando a Cultura DevOps para resolver problemas de versionamento, integração e automação.

## 2. Objetivo
Estabelecer um fluxo de trabalho colaborativo, organizado, automatizado e confiável utilizando Git, GitHub, Docker e pipelines de Integração Contínua (CI).

## 3. Tecnologias Utilizadas
* **Versionamento:** Git e GitHub
* **Containerização:** Docker
* **Integração Contínua (CI):** GitHub Actions
* **Linguagem/Base:** HTML5 / Nginx

## 4. Estrutura de Pastas
```text

├── .github/

│       └── ci.yml
```
